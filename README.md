# Яркий Ставрополь — Моя Родина

Статический информационный портал города Ставрополь: семь страниц о городе, достопримечательностях, культуре, бизнесе, туризме и контактах. Сервер и сборка не нужны — достаточно открыть `index.html`.

## Структура

```
index.html          главная
about.html          о городе
attractions.html    достопримечательности
culture.html        культура и события
business.html       справочник бизнеса
tourism.html        туризм и экскурсии
contact.html        контакты
css/styles.css      дизайн-система и адаптив
js/images.js        привязка локальных фотографий по data-image
js/main.js          меню, модалки, фильтры, счётчики, кнопка «наверх»
js/slider.js        слайдеры (hero и отзывы)
js/gallery.js       lightbox-галерея
js/forms.js         валидация и отправка форм
js/footer.js        единый подвал для всех страниц
images/             локальные фотографии Ставрополя
```

## Дизайн

Дизайн выполнен по прикреплённому референсу: глубокий тёмно-зелёный фон `#0b2623`, кремовый текст `#efe9d9`, тёплый акцент `#e6d7ac`. Жирные заголовки в верхнем регистре (Montserrat 900), крупное «призрачное» число `1777` в hero, вертикальная социальная панель слева, нижняя полоса навигации слайдера с названиями соседних слайдов, панель быстрых ссылок в стиле «+ РАЗДЕЛ». Галерея — горизонтальная карусель со scroll-snap. Все изображения — локальные фотографии Ставрополя из папки `images/`. Единый тёмный стиль применён ко всем семи страницам (формы, CTA, карточки, модалки, контакты).

Актуальные данные сверены с Википедией (2025–2026): население 562 964, основан в 1777 году, 20 вузов, 5 музеев, 2 театра, 1450 км от Москвы, средняя температура января −2,3 °C.

## Возможности

- Полноэкранный hero-слайдер с тремя фотографиями и автопрокруткой;
- анимированные счётчики, бегущая строка, быстрые ссылки по разделам;
- галерея с lightbox (клавиши ←/→/Esc);
- фильтры по категориям на страницах достопримечательностей и бизнеса;
- модалки подписки и регистрации с валидацией email/телефона;
- мобильное меню, кнопка «наверх», доступные подписи и управление с клавиатуры.

Подробная история изменений — в [`CHANGELOG.md`](CHANGELOG.md).
